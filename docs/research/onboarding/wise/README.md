# Wise (TransferWise) — Money Transfer Onboarding Analysis

> **Industry:** Fintech / Cross-Border Money Transfer | **Type:** Consumer + Business KYC/KYB | **Rating:** 4.4/5 | **Date:** 2026-08-05

## Executive Summary
Wise (16M+ users, $25B+ quarterly volume) built onboarding around **transparent, low-cost cross-border transfers.** KYC is progressive: small transfers (<$1K) require basic ID; larger transfers trigger enhanced verification. Multi-currency account with local bank details in 10+ currencies requires full KYC. The mid-market exchange rate promise (no hidden markup) is the conversion hook.

| Dimension | Rating | Key Pattern |
|-----------|--------|-------------|
| Field Minimization | 4 | Progressive: small transfers → basic ID; large transfers → enhanced KYC. Multi-currency account: full KYC |
| Risk Intelligence | 4 | Transaction monitoring across 50+ currencies. Travel Rule for crypto. AML/CTF with multi-jurisdictional compliance |
| Conversion | 4 | "Send money with the real exchange rate" — transparent fee comparison vs banks. First transfer free (up to $500) |
| Entitlement | 4 | Transfer limits scale with verification depth. Multi-currency account = full KYC. Business: additional KYB |
| Agentic/AI | 3 | Auto-convert at target rate, scheduled transfers, AI-powered rate alerts |

## Key Insight: Progressive Transfer Limits
Wise's model: **transfer amount = verification depth.** Sending $100: basic ID. Sending $1,000: enhanced ID. Sending $10,000: proof of source of funds. Sending $100,000: full source of wealth documentation. The user's own transfer ambition drives voluntary KYC completion.

## Top QBO Takeaway
- **Transaction-value-driven KYC** — QBO payroll/tax filing limits scale with verification depth. Run $500 payroll: basic. Run $10,000 payroll: enhanced.
- **Transparent fee comparison** — Wise's "we're 8x cheaper than banks" is the #1 conversion message. QBO should quantify time/money saved vs. manual accounting.
