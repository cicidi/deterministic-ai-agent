# Optum (UnitedHealth Group) — Healthcare Platform Onboarding | **Rating:** 2.5/5 | **Date:** 2026-08-05

Optum (UNH's health services division, $186B+ revenue) is the **B2B healthcare infrastructure** — serves providers, payers, employers, and pharma. OptumRx (PBM, competing with Express Scripts/Caremark), OptumInsight (healthcare analytics/consulting), OptumHealth (care delivery). Provider onboarding: NPI number, DEA registration, state medical license, board certification, group practice affiliation, facility address, Medicare/Medicaid enrollment. Unlike consumer health insurers, Optum vets healthcare providers, not patients.

**Key insight:** Provider onboarding (not consumer) — Optum verifies doctors, not patients. This is the "other side" of healthcare KYC. NPI + DEA + medical license + board certification + Medicare enrollment creates a credential stack QCBO should study for verifying accountants in its network.
