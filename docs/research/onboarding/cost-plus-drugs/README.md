# Mark Cuban Cost Plus Drugs — Transparent Pharmacy | **Rating:** 3.5/5 | **Date:** 2026-08-05

Cost Plus Drugs (Mark Cuban's transparent pharmacy) sells **generic medications at cost + 15% + $3 pharmacy fee + $5 shipping.** Onboarding: create account (name, email, address), add prescriptions (drug name, dosage, prescribing doctor), upload prescription or have doctor e-prescribe, pay (no insurance accepted — keeps it simple). ZERO insurance verification, ZERO prior authorization, ZERO PBM middlemen. The simplest pharmacy onboarding in the research.

**Key insight:** Removing insurance from the equation eliminates 90% of pharmacy onboarding complexity. No insurance ID verification, no formulary check, no prior auth, no PBM. QBO equivalent: "cash-basis accounting only, no tax integration needed" — dramatically simpler onboarding for a specific segment.
