# Charles Schwab — Full-Service Brokerage Onboarding
> **Industry:** Banking + Brokerage | **Rating:** 3.2/5 | **Date:** 2026-08-05

## Executive Summary
Schwab (largest publicly traded US brokerage, $8.5T+ client assets, acquired TD Ameritrade 2020) represents the **full-service brokerage onboarding model.** Unlike Robinhood (mobile-first, gamified), Schwab's onboarding is comprehensive: checking + brokerage + IRA + 529 + trust accounts all in one relationship. Schwab Intelligent Portfolios (robo-advisor, $5K min). No minimum for brokerage. Schwab Bank (checking + savings). Global ATM fee rebates (Schwab Bank High Yield Investor Checking). 400+ branches for in-person onboarding.

**Key insight:** Schwab proves that full-service doesn't mean slow — $0 commission, $0 minimum brokerage removed the largest barriers. The TD Ameritrade acquisition added thinkorswim (active trader platform) without disrupting onboarding. QBO: "No minimum, no setup fee, explore the dashboard before committing" is the Schwab playbook.
