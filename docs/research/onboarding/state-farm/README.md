## State Farm vs Geico — The 15-Minute Gap
| Scenario | State Farm | Geico |
|----------|-----------|-------|
| **Start quote** | Enter ZIP → "Find an agent near you" → list of agent phone numbers | Enter ZIP → begin quote flow immediately |
| **Complete purchase** | Call agent → schedule meeting → discuss coverage → agent enters data → wait for underwriting → sign paperwork. Days | 15-minute online quote → bind policy → digital ID card in Apple Wallet |
| **After hours** | Agent office closed. Leave voicemail. Wait for callback | 24/7 self-serve. Quote anytime. Buy anytime |
| **Mobile-first 25-year-old** | Must call a stranger and schedule a meeting. "Do I really need to TALK to someone to buy insurance?" | Opens app. 11 fields. Buys policy. Never talks to a human |

19,000+ exclusive agents are State Farm's distribution MOAT — and their innovation ANCHOR. Every incentive in the organization protects the agent channel at the expense of digital. A 25-year-old's first interaction with State Farm is a phone call to a stranger. That's a lost generation.

**Lesson for QBO:** Accountants are QBO's agents. They're a MOAT. But if QBO requires an accountant for signup, the vast majority of self-serve SMBs go elsewhere.
