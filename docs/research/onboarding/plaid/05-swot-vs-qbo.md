# Plaid — SWOT vs Intuit QuickBooks Online

## Plaid SWOT

### Strengths
- **3-field signup** — industry best minimization
- **Trial Plan** — auto-approved real data access with capped scope; skipped security questionnaire
- **5-tier progressive access** with per-product use case justification
- **5 MCP/AI integrations** — Dashboard MCP, Sandbox MCP, AI Toolkit, Fin, Sierra
- **Per-Item product gating** — auto / update mode / impossible post-creation
- **12,000+ institutions** — network effects

### Weaknesses
- No platform API prefill (Stripe/PayPal have this)
- Production review adds days/weeks
- Two-sided audience confusion (consumers + developers)
- SDK maintenance across 5+ languages

## Direct Comparison

| Dimension | QBO | Plaid | Winner |

| Signup fields | ~25-30 | **3** | **Plaid** |

| Developer experience | Not dev-first | **Copy-paste quickstart + MCP + AI toolkit** | **Plaid** |
