# GEICO — Auto Insurance Onboarding
> **Industry:** Insurance / Auto | **Rating:** 4.5/5 | **Date:** 2026-08-05

## Executive Summary
GEICO (2nd largest US auto insurer, Berkshire Hathaway) built the legendary **"15 minutes could save you 15% or more"** onboarding — a wizard-style digital flow optimized for single-session quote-and-buy. ZIP code is the ONLY first screen field. Progressive disclosure: one question per screen. Behind the scenes: MVR pull (state DMV), CLUE report (LexisNexis claims), credit-based insurance score. Digital ID card instantly on purchase. DriveEasy telematics (47 states) for usage-based scoring. 97% customer satisfaction (2025). GEICO Mobile #1 rated by Forrester.

**Key insight:** GEICO proves that single-field-per-screen progressive disclosure + famous time-bound promise = the gold standard insurance conversion engine. QBO: "Set up your business accounting in 15 minutes."
