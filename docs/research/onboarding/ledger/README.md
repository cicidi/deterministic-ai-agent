# Ledger — Crypto Hardware Wallet Onboarding | **Rating:** 3.5/5 | **Date:** 2026-08-05

Ledger (6M+ devices sold) is the **hardware wallet standard** for crypto self-custody. UNIQUE: onboarding is hardware-driven — unbox device → install Ledger Live app → generate seed phrase (24 words) → verify seed phrase → set PIN → connect to Ledger Live → install crypto apps → transact. NO KYC/AML (self-custody). Ledger Recover (2023, controversial): optional seed phrase backup service requiring KYC (ID + selfie via Onfido). Ledger Stax (new touchscreen device, designed by Tony Fadell/iPod designer).

**Key insight:** Ledger's hardware-anchored onboarding mirrors Square's card-reader model: the physical device IS the trust anchor. Seed phrase = the ultimate onboarding challenge (lose it = lose everything). Ledger's UX problem: seed phrase management is the highest-stakes onboarding step in all of fintech.
