# Allstate — Auto + Home Insurance Onboarding
> **Industry:** Insurance / Auto + Home | **Rating:** 3.8/5 | **Date:** 2026-08-05

## Executive Summary
Allstate (4th largest US auto insurer, $64B revenue) is unique for its **hybrid agent+digital model** — 10,000+ captive agents AND full digital quoting. Esurance was their digital-first brand (2011-2020, acquired $1B, later absorbed). Drivewise telematics (10% signup discount, up to 40% renewal, rates never increase). Milewise pay-per-mile for low-mileage drivers. Accident Forgiveness from day one. Deductible Rewards ($100 at signup + $100/yr). Hybrid model creates complex dual-funnel onboarding — same underwriting data captured through both agent (guided) and digital (self-service) channels.

| Dimension | Rating | Key Pattern |
|-----------|--------|-------------|
| Field Minimization | 3 | Auto: SSN, DL, VIN, prior insurance. Home: 25+ property fields. ZIP code gateway — some areas agent-only |
| Pre-fill Strategy | 2 | VIN auto-decode. Prior insurance lookup. No platform API prefill |
| Risk Intelligence | 4 | MVR + CLUE + credit-based score + home property CLUE + ISO Public Protection Classification |
| Conversion | 4 | Dual-funnel (agent + digital). Drivewise non-punitive telematics. Accident Forgiveness day one |
| Agentic/AI | 3 | QuickFoto Claim AI, Drivewise, AI-generated agent emails. No MCP |
| Entitlement | 4 | Coverage ladder. Milewise pay-per-mile. Bundling up to 30% discount. Deductible Rewards. |

**Key insight:** Hybrid agent+digital = same KYC data, two different abandonment risks. Agent channel handles SSN/credit pull naturally; digital channel drops at each sensitive field. QBO equivalent for accountant-assisted + self-serve dual onboarding.

**QBO takeaway:** Non-punitive telematics (Drivewise never raises rates) = trust-driving pattern. QBO: usage-based pricing that rewards but never penalizes.
