# Cigna — Health Insurance Onboarding
> **Industry:** Healthcare / Health Insurance | **Rating:** 3.5/5 | **Date:** 2026-08-05

## Executive Summary
Cigna (~19M medical members) has a unique structural advantage: the 2018 Express Scripts acquisition created **integrated medical + pharmacy onboarding** — one signup activates doctor visits AND prescriptions. Competitors (UNH/OptumRx, Anthem/CarelonRx) also own PBMs, but Cigna's integration is deeper — Express Scripts + MDLive telehealth live under one Evernorth division, creating a "sign up once, get doctor + pharmacy + telehealth" experience. The myCigna app unifies digital ID cards (medical/dental/vision/pharmacy on one card), provider search, claims, pharmacy, and telehealth behind a single login.

| Dimension | Rating | Key Pattern |
|-----------|--------|-------------|
| Field Minimization | 4 | Employer channel: near-zero. Individual: SSN, DOB, dependents. No credit check. MIB only for non-ACA plans |
| Pre-fill Strategy | 4 | Employer census file auto-populates. ACA marketplace API for subsidy verification. CMS MARx for Medicare |
| Risk Intelligence | 4 | MIB + Express Scripts PBM database + PDMP + CMS validation. Medical underwriting only for non-ACA plans |
| Conversion | 4 | Employer auto-enrollment = frictionless. Integrated medical+pharmacy = single signup value proposition |
| Agentic/AI | 3 | myCigna AI chatbot, MDLive virtual visits, Express Scripts auto-refill. No MCP/A2A |
| Entitlement | 3 | Coverage tier ladder (Bronze→Platinum). Pharmacy formulary tiers. Prior auth gates for specialty drugs |

**Key insight:** One unified ID card (medical + dental + vision + pharmacy) + single login for everything eliminates the #1 healthcare UX pain point: juggling separate portals. QBO equivalent: one QBO dashboard for accounting + payroll + tax + banking — not separate products.

**QBO takeaway:** Integrated platform UX — single login, single dashboard, unified experience across all products. Cigna proves that acquiring adjacent services (Express Scripts PBM, MDLive telehealth) and unifying them behind one login creates the strongest retention moat.
