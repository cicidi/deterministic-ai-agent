# DailyPay — Employer-Sponsored Earned Wage Access | **Rating:** 3.8/5 | **Date:** 2026-08-05

DailyPay (B2B earned wage access — different from EarnIn's B2C model) provides **employer-sponsored on-demand pay.** Employer integrates DailyPay with payroll system (ADP, UKG, Workday, etc.). Employee onboarding: acknowledge terms, link bank account or DailyPay card. No SSN collection by DailyPay — employer already verified employee. DailyPay tracks hours worked in real-time via time/attendance integration, shows "available pay" balance, employee transfers to bank instantly or next-day. $2.99 per transfer (instant) or free (next day). Used by Hilton, Target, Dollar Tree, Kroger, Adecco.

**Key insight:** Employer-integrated model = DailyPay skips KYC entirely (employer already did it) — near-zero employee friction. The B2B2C approach to KYC. QBO: accountant-verified onboarding where the accountant's verification satisfies QBO's KYC requirements.
