# Revolut — Global Neobank Onboarding Analysis

> **Industry:** Fintech / Global Neobank | **Type:** Consumer + Business KYC/KYB | **Rating:** 4.3/5 | **Date:** 2026-08-05

## Executive Summary
Revolut (40M+ users, 50+ countries) built a **multi-product financial superapp** with onboarding that scales from instant basic access to full banking, crypto, trading, and business accounts. Core insight: **geographic KYC adaptation** — onboarding requirements vary by jurisdiction but UX remains consistent. No physical branches. 100% mobile.

## Key Insight: Geographic KYC Adaptation
Revolut's single biggest innovation is **same UX, different KYC per country.** A US user sees SSN request; a UK user sees passport + proof of address; a Polish user sees PESEL number. The backend compliance engine routes verification differently per jurisdiction — but the user experience is identical. This is the model for any global regulated product.

## Top QBO Takeaway
- **Geographic compliance engine** — same onboarding UX, different regulatory requirements per country. QBO's US-only onboarding could expand globally with this pattern.
- **Superapp progressive model** — standard → money transfer → crypto → stock trading → metal card. QBO: basic → payroll → tax → lending.
