# Rocket Mortgage — Digital Mortgage Onboarding | **Rating:** 4.2/5 | **Date:** 2026-08-05

Rocket Mortgage (largest US mortgage lender, $300B+ origination volume) built the **first fully digital mortgage application.** Onboarding: SSN (soft pull for pre-approval → hard pull at application), income verification (W-2s, pay stubs, tax returns uploaded or linked via payroll integration), asset verification (bank statements, retirement accounts, gift letters), employment verification (automated via The Work Number/Equifax), property details (address, purchase price, down payment, type), debt declaration. Rocket Logic AI automated underwriting — 10-minute pre-approval. Rocket Homes (real estate marketplace), Rocket Auto, Rocket Solar.

**Key insight:** Rocket's doc upload automation — bank statements linked via Plaid, income verified via payroll API, employment verified via The Work Number. The fewer manual documents uploaded, the faster the mortgage closes. QBO: auto-fetch bank statements, payroll data, and tax records instead of asking users to upload.
