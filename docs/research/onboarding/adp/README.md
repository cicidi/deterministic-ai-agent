# ADP — Enterprise Payroll Onboarding | **Rating:** 2.5/5 | **Date:** 2026-08-05

ADP (1M+ clients, 40M+ employees) is **traditional enterprise payroll.** Onboarding: EIN, state/local tax IDs, employee SSNs, prior payroll migration, bank verification, tax agency setup. Enterprise: 4-12 week implementation. RUN by ADP (SMB), Workforce Now (mid-market), Vantage (enterprise). Complex, powerful, slow — the baseline Gusto disrupts.

**Key insight:** ADP's complexity IS its moat — multi-state, multi-EIN, multi-country payroll is genuinely hard. QBO must handle both simple self-serve AND complex accountant-assisted paths.
