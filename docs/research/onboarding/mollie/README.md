# Mollie — European SMB Payment Gateway | **Rating:** 4.0/5 | **Date:** 2026-08-05

Mollie (Netherlands-based, 200K+ merchants, processes for 15 European countries) is the **European Stripe for SMBs.** Focus on local EU payment methods (iDEAL 45% Netherlands market, Bancontact Belgium, SOFORT/Sofortüberweisung Germany, Giropay, EPS Austria, Multibanco Portugal). Onboarding: self-serve KYB with Chamber of Commerce (KvK) lookup, UBO declaration, bank account verification, website check. Known for simple API + fast onboarding (minutes, not days). Mollie Terminal (in-person payments).

**Key insight:** Mollie's Kamers van Koophandel (Chamber of Commerce) integration auto-verifies Dutch business registration via API — the EU equivalent of Secretary of State lookup. QBO: integrate with Secretary of State APIs for instant business verification.
