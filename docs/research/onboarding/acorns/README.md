# Acorns — Micro-Investing Onboarding | **Rating:** 4.0/5 | **Date:** 2026-08-05

Acorns (9M+ users) pioneered **micro-investing via spare change roundups** — the lowest-friction investment onboarding in existence. Onboarding: SSN, ID, DOB, address, link bank account (Plaid), select portfolio (conservative → aggressive), link payment cards for roundups. The roundup mechanic IS the onboarding — every purchase rounds up to the nearest dollar, spare change invested. $3-5/mo subscription (Acorns Personal/Personal+/Family). Acorns Later (IRA). Acorns Early (UTMA/UGMA custodial). Found Money (cashback from 450+ brands to Acorns).

**Key insight:** Roundups = the most psychologically frictionless onboarding-to-first-transaction in fintech. Users don't "decide to invest" — the investing just happens automatically. QBO: "every transaction auto-categorizes, every invoice auto-generates" — automatic accounting that users don't need to "do."
