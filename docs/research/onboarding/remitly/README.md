# Remitly — Digital Remittance Onboarding | **Rating:** 3.8/5 | **Date:** 2026-08-05

Remitly (5M+ customers, public RELY) is the **largest digital-first remittance company** — competing with Western Union/MoneyGram for the $700B+ global remittance market. Onboarding: name, address, phone, email, SSN/ID (varies by send amount: small transfers = basic ID; large = enhanced KYC), recipient name/bank details, funding source (bank account, debit card, credit card), delivery method (bank deposit, cash pickup, mobile wallet, home delivery in some markets). Transfer corridors: US → India, Mexico, Philippines, China, etc. 3,000+ corridors.

**Key insight:** Remittance KYC is tiered by transfer amount — $500 transfer = basic verification; $5,000 = full KYC + source of funds. This is the Wise model applied to consumer remittances. QBO: feature access scales with entity verification depth.
