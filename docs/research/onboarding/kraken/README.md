# Kraken — Security-First Crypto Exchange Onboarding
> **Industry:** Crypto / Exchange | **Rating:** 3.8/5 | **Date:** 2026-08-05

## Executive Summary
Kraken (US-based, 10M+ users) is the **security-first crypto exchange** — "security above all else." Founded 2011, never hacked (unlike MtGox, Bitfinex, Coincheck). Onboarding: 3-tier KYC (Starter/Intermediate/Pro) with Kraken's Proof of Reserves audit. Kraken Bank (SPDI charter in Wyoming, 2020 — first US crypto bank). Kraken Pro for advanced trading. Kraken's compliance culture means slower onboarding but stronger regulatory trust.

| Dimension | Rating | Key Pattern |
|-----------|--------|-------------|
| Field Minimization | 3 | Starter tier: name, DOB, address, phone. Intermediate: photo ID + selfie. Pro: proof of source of funds |
| Risk Intelligence | 5 | "Never been hacked" track record. Proof of Reserves audit. Penetration testing culture. SPDI bank charter |
| Conversion | 3 | Compliance-first = slower approval. "Security above all else" = attracts security-conscious, loses impatient |
| Agentic/AI | 2 | Limited. Kraken Pro trading interface. Staking rewards. OTC desk |
| Entitlement | 4 | Starter → Intermediate → Pro. Futures trading. Margin (3-5x). OTC. Kraken Bank integration |

**Key insight:** Kraken's "never been hacked" = security as brand = compliance-first onboarding. The trade-off: slower onboarding loses impatient users to Binance but attracts institutional capital that values security over speed.
