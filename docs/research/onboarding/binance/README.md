# Binance — Global Crypto Exchange Onboarding
> **Industry:** Crypto / Exchange | **Rating:** 3.5/5 | **Date:** 2026-08-05

## Executive Summary
Binance (largest global crypto exchange by volume, 200M+ users) operates with the **most tiered KYC in crypto**: Level 1 (email only, 2 BTC/day withdrawal), Level 2 (photo ID + selfie, 100 BTC/day), VIP (enhanced KYC, OTC, institutional). Binance Pay, Binance Card, Binance Earn. Unlike Coinbase (conservative, public company), Binance is aggressive on features and global reach. Regulatory pressure from US (Binance.US separate entity), EU (MiCA), UK (FCA ban on Binance Markets).

**Key insight:** Binance's VIP tier system (9 levels, volume + BNB holdings) is the most sophisticated crypto entitlement model. Higher tiers = lower fees, higher withdrawal limits, dedicated account manager, OTC desk access. QBO equivalent: usage-based pricing tiers that unlock with transaction volume.
